A two-part micro-confession — a `To:` line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed — produced by a small deterministic program for make.fun's "Unsent: The Micro-Confession Sprint" bounty. Fourteen candidate lines were drafted and weighed against the judge's published brief; the strongest survived: a secret kept for fifteen years, where the reason it stayed in drafts is felt in the words, never stated.

## Run it

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt` (123 characters, inside the 1–260 gate; the message itself is 106 characters, inside the 200 limit). The same text on every run — no network, no secrets, no randomness.
